# SketchTool-Tuari

[中文](./README.md) / [English](./README_EN.md)

Tauri + Rust で再構築されたデスクトップスケッチ練習ツールです。元のプロジェクトの基本的な使用方法を維持しながら、macOS のウィンドウ操作、画像スライドショー、平均色背景、グリッドオーバーレイ、ライブラリ体験などを調整しています。

## 機能

- ローカル画像フォルダを選択してスケッチ練習を開始
- ランダム / 順序再生に対応
- マーク済み画像のフィルター機能
- 画像ライブラリのブラウズ、外部で開く、マーク解除
- ミラー、グレースケール、グリッドオーバーレイツール
- 単色、平均色、静的画像背景
- カウントダウン表示と時間形式の切り替え
- デフォルトフォルダ、起動フォルダ、ウィンドウ最前面表示対応
- macOS スタイルのウィンドウドラッグとトラフィックライト表示制御
- お絵かきモード：参照画像を自動的に薄く表示して描画ボードを有効化
- 模写モード：右側に同サイズの白いキャンバスを配置し、グリッド同期とレイヤーパネルに対応
- タブレット筆圧、複数レイヤー、HSL カラーピッカー、バケツ塗りつぶしに対応

## ショートカットキー

スライドショー：

| ショートカット | 機能 |
| --- | --- |
| スペース | 一時停止 / 再開 |
| ← / → | 前の画像 / 次の画像（長押しで連続切替） |
| M | ミラー切り替え |
| G | グリッド切り替え |

描画モード（お絵かき / 模写）：

| ショートカット | 機能 |
| --- | --- |
| B | ペンツール |
| E | 消しゴムツール |
| [ / ] | ブラシを小さく / 大きく（長押しで連続調整） |
| ⌘Z / Ctrl+Z | 元に戻す |
| ⌘⇧Z / Ctrl+Y | やり直し |
| Esc | 描画モードを終了 |

補助操作：

- スタイラスのサイドボタン（タブレットドライバーで「消しゴム」に割り当て）を押している間だけ消しゴムになり、離すと前のツールに戻ります。右 / 中ボタンのドラッグも同様です。
- ショートカットは物理キーで判定するため、中国語入力などの IME が有効なままでもそのまま使えます（英語入力への切り替え不要）。

## 技術スタック

- フロントエンド: Vanilla JavaScript + Vite
- デスクトップ: Tauri 2
- バックエンド: Rust

## 開発

依存関係のインストール：

```bash
npm install
```

開発モードで実行：

```bash
npm run tauri dev
```

## ビルド

デバッグビルド：

```bash
npm run tauri build -- --debug --bundles app
```

リリースビルド：

```bash
npm run tauri build -- --bundles app
```

## 備考
